# MercerMedia – Shopify Hydrogen Headless Commerce Store

A modern Headless eCommerce Store built using **Shopify Hydrogen**, **React**, **GraphQL**, and the **Shopify Storefront API**.

---

## 🚀 About

MercerMedia is a modern fashion eCommerce application developed with Shopify Hydrogen. The project showcases a production-style headless storefront that delivers fast performance, responsive design, and a seamless shopping experience.

It includes product collections, product detail pages, predictive search, shopping cart, customer accounts, blogs, related products, SEO optimization, and mobile-first responsive layouts.

---

- Responsive Design
